今日兴起，准备在谷歌搜索自己的域名看看会搜出什么，结果真的能搜出来自己的博客！页面顶端提醒我尝试使用 Google Search Console，我对此有兴趣，一起看看里面有什么。

![关键词 site:0f.nz 在 google.com 的搜索结果，在搜索结果顶部 Google 提示尝试使用 Google Search Console](./googleseo01.jpg)

进入 Google Search Console 后，添加网域。按照图示填写域名并点击“验证”按钮。

![Google Search Console 的欢迎界面](./googleseo02.jpg)
![Google Search Console 点击“认证”按钮后的“加载中”弹窗](./googleseo03.jpg)
![Google Search Console 点击“认证”按钮后的弹窗，标题为“通过 DNS 记录验证域名所有权”](./googleseo04.jpg)

因为我的域名托管在 Cloudflare，所以使用它来认证。这个流程十分方便。

![Cloudflare 授权来自 Google 的 DNS 记录](./googleseo05.jpg)

授权成功后自动跳转回 Google Search Console。

![Google Search Console “正在验证”弹窗](./googleseo06.jpg)

成功验证域名所有权！🎉

![Google Search Console “已完成所有权认证”弹窗](./googleseo07.jpg)

Google Search Console 的管理界面是长这样的，很简洁美观，见识到了。

![Google Search Console 的管理界面](./googleseo08.jpg)
